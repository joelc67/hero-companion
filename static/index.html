💠 How set bonuses stack

Slot 2 or more pieces of the same IO set in one power and bonuses unlock tier by tier — each power card's sets: line names its sets, and the ⓘ on any piece lists every tier.

The rule of five: the game counts each identical bonus at most 5 times across your whole build — a sixth copy adds nothing. The planner obeys this automatically; if you hand-slot, it's the one trap to watch.

To see where any total comes from, open Stats and click the number — the exact pieces feeding it ring green.
